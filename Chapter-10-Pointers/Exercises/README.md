# Chapter 10 - Exercises

Use these exercises to put into practice the knowledge you have gained from chapter 10. You can save your solutions to the exercises to this repository and it is recommended that for each exercise you create a _**new project**_ with the name of the exercise and save it to the relevant exercise folder for the chapter you are working on. Once you have completed your solution you should make sure you commit and push the code to your remote repository on GitHub.

&nbsp;

### 1 - What’s the Point 

Declare an int variable and int pointer and assign the value of the int via user input. Next output the following:

* The value of the variable
* The address of the variable
* The value of the variable via pointer

&nbsp;
&nbsp;

### 2 - Making Memories

Write a simple program that **allocates memory** (e.g. using ```new```) for an integer variable and string variable. Do the following for both these variables.

* Output the memory address
* Output the value
* Alter the value
* Output the new value

&nbsp;
&nbsp;

### 3 - Point to the Max

Write a C++ program to find the max value of an int array. The program should ask the user the size of the array, then **allocate memory** for this array using a pointer. Once the array has been created in memory the program should ask the user to enter values for the array.

Once the array is full the program should find the max value and output it to the console.
