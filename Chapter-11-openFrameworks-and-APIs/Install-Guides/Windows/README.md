# Installing openFrameworks for Windows

This guide is for installing openFrameworks for Windows using either Visual Studio or VS Code. If you are struggling to get things working please let your module tutor know. 

&nbsp;
&nbsp;

## Download openFrameworks

Start by downloading the version of openFrameworks for your chosen code editor:

- [Windows VS Code](https://github.com/openframeworks/openFrameworks/releases/download/0.12.1/of_v0.12.1_msys2_mingw64_release.zip) 
- [Windows Visual Studio](https://github.com/openframeworks/openFrameworks/releases/download/0.12.1/of_v0.12.1_vs_64_release.zip)

&nbsp;
&nbsp;

## Unzip the Download

Once the file has downloaded extract the contents and save the folder somewhere sensible. For example mine is saved in ```Documents → Dev → C++ → openFrameworks```. 

*It is advised that you avoid saving openFrameworks in a location that includes spaces in the file path*

&nbsp;
&nbsp;

## Setup for VS Code
If you are using VS Code additional steps are required to setup openFrameworks. If you are using Visual Studio you can skip this section.

- Follow the [instructions available here](https://openframeworks.cc/setup/msys2/) to install MSYS2 and compile openFrameworks
- Follow the [instructions available here](https://openframeworks.cc/setup/vscode/) under the COMMON heading to run a project

If you've followed the instructions correctly everything should now be ready to go!

&nbsp;
&nbsp;

That was easy wasn't it. openFrameworks is now ready to go.
