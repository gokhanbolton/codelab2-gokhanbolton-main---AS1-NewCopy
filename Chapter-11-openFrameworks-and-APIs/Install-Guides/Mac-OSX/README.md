# Installing openFrameworks for Mac OSX

This guide is for installing openFrameworks for Mac OSX and is suitable for both VS Code & Xcode. If you are struggling to get things working please let your module tutor know. 

&nbsp;
&nbsp;

## Download openFrameworks

Start by downloading the version of openFrameworks available  [here](https://github.com/openframeworks/openFrameworks/releases/download/0.12.1/of_v0.12.1_osx_release.tar.gz).


&nbsp;
&nbsp;

## Unzip the Download

Once the file has downloaded extract the contents and save the folder somewhere sensible. For example mine is saved in ```Documents → Dev → C++ → openFrameworks```. 

*It is advised that you avoid saving openFrameworks in a location that includes spaces in the file path*

&nbsp;
&nbsp;

## You are Ready

That was easy wasn't it. openFrameworks is now ready to go. For further information on how to create and run projects see the following guides:

- [VSCode](https://openframeworks.cc/setup/vscode)
- [Xcode](https://openframeworks.cc/setup/xcode)
