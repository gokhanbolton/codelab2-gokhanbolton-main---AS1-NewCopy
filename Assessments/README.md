# Assessments

CodeLab II features two summative assessments that contribute to your module mark

## S1. Programming Skills Portfolio (40%)

Develop solutions to a series of coding challenges that demonstrate your understanding of the programming techniques introduced through the course of the module. 

**Deadline: Staged throughout the module**

The [Programming Skills Portfolio folder](./S1-Programming-Skills-Portfolio/) provides an overview of the brief and includes the instructions for each exercise required by the assessment. You should use this folder to submit your code.

## S2. Data Driven Application (60%)

Development of a desktop application in C++ that retrieves data from an API. This submission must be supported by a development document.

**Deadline: 16 January 2025**

The [Data Driven App folder](./S2-Data-Driven-App/) contains a starter template for generating the openFrameworks project required for the assessment, alongside starter code for each API option listed on the brief. This folder should be used to submit the final project.
